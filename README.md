# 🍰 Sistema de Gestão de Encomendas – Loja de Doces

Aplicação web desenvolvida para **organizar encomendas, horários de produção e status de pagamentos** de uma loja de doces, salgados e tortas, especialmente em períodos de alta demanda como o final de ano.

O sistema é de **uso interno**, focado em simplicidade, rapidez e boa experiência em dispositivos móveis.

---

## 📌 Funcionalidades

### 🧁 Encomendas
- Cadastro de encomendas com:
  - Nome do cliente
  - Telefone
  - Tipo do produto (Doce, Salgado ou Torta)
  - Descrição do pedido
  - Quantidade
  - Data e horário
  - Retirada ou entrega
- Controle de status do pedido:
  - A fazer
  - Em preparo
  - Pronto
  - Entregue

---

### 📅 Agenda
- Visualização das encomendas por dia
- Ordenação por horário
- Destaque para pedidos pendentes ou atrasados
- Facilita a organização da produção diária

---

### 💰 Controle Financeiro
- Status de pagamento:
  - Pendente
  - 50%
  - Pago
- Visão geral de:
  - Total recebido
  - Total pendente
  - Pedidos parcialmente pagos
- Filtros por período (dia, semana, mês)

---

## 📱 Design e Usabilidade
- Interface **mobile-first**
- Layout simples e intuitivo
- Componentes visuais claros (cards, ícones e cores suaves)
- Pensado para uso rápido no dia a dia da loja

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React / Next.js
- **UI:** Tailwind CSS + shadcn/ui
- **Prototipação e UI:** v0
- **Arquitetura:** Componentização e organização por telas

---

## 🎯 Objetivo do Projeto

Este projeto foi criado para resolver uma **necessidade real de organização de encomendas**, reduzindo erros, conflitos de horários e facilitando o controle financeiro durante períodos de grande volume de pedidos.

Além disso, o sistema serviu como prática de:
- Construção de interfaces responsivas
- Modelagem de fluxo de pedidos
- Foco em usabilidade e experiência do usuário
